# RestaurantMemo

RestaurantMemo は、飲食店の情報と来店記録を残すための Android アプリです。

行ったお店、注文したもの、感想、評価、写真などをまとめて記録し、あとから検索やタグで探しやすくすることを目的にしています。

この README は v0.1.0 時点の内容をまとめたものです。

## 主な機能

- 店舗登録 / 編集 / 削除
- 来店記録登録 / 編集 / 削除
- 来店記録への写真追加
- タグ管理
- 店名 / タグ検索
- お気に入り登録
- 店舗一覧の並び替え
  - 登録順
  - お気に入り順
  - 来店回数順
  - 最近行った順
  - 平均評価順
- Room によるローカル保存

## 技術構成

- Kotlin
- Jetpack Compose
- Room
- ViewModel

## データ保存について

登録した店舗、来店記録、タグ、お気に入り状態などのデータは、端末内の Room データベースに保存されます。

外部サーバーへの送信は行いません。
